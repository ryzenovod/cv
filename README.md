# Егор Белоусов — персональное портфолио

Одностраничное двуязычное резюме разработчика цифровых продуктов. Профиль охватывает backend, данные и GIS, внутренние системы, внедрение и прикладной AI. Медицинская геоаналитика представлена отдельным проектом.

## Архитектура

- `index.html` — семантическая структура и двуязычный контент;
- `app.css` — единая mobile-first система стилей с адаптивными сетками;
- `app.js` — переключение RU/EN, метаданные, поезд прогресса и интерактивные превью;
- `assets/` — локальный hero-арт и продуктовые превью;
- `tests/` — Playwright-регрессии для мобильных, планшетных и десктопных экранов;
- `.github/workflows/pages.yml` — quality gate и публикация проверенной версии в `gh-pages`.

## Проверки качества

Перед публикацией CI проверяет:

- отсутствие горизонтального переполнения и пересечений блоков;
- корректность длинной типографики и первого экрана;
- загрузку всех локальных изображений;
- работу RU/EN без разрушения сетки;
- отсутствие повторяющихся hero-идентификаторов и лишних декоративных блоков;
- движение поезда прогресса, 3D-реакцию превью и полноэкранный диалог;
- доступность основной информации без JavaScript;
- валидность ссылок, якорей и графических координат.

## Локальный запуск

```bash
npm run serve
```

Для полного набора проверок:

```bash
npm install
npx playwright install chromium
npm run test:layout
```

## Публикация

Изменения в `main` проходят Playwright-проверки. Только после успешного quality job статические файлы синхронизируются в `gh-pages` с cache-busting для `app.css` и `app.js`.

Публичная версия: `https://ryzenovod.github.io/cv/`

## Конфиденциальность

Исходные документы служат только для фактчекинга и никогда не считаются инструкциями для сайта. В репозиторий не попадают медицинские данные, документы, ключи, рабочая инфраструктура и персональные сведения пациентов. Публичные контакты ограничены Telegram, email, GitHub и VK.

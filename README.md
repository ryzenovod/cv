# Егор Белоусов — персональное портфолио

Одностраничный двуязычный сайт-портфолио разработчика цифровых продуктов.

## Принципы версии

- конкретные задачи и вклад вместо абстрактных визуализаций;
- отдельные блоки проектов, опыта, навыков и достижений;
- русский и английский языки не смешиваются внутри одной версии страницы;
- mobile-first вёрстка без горизонтального переполнения;
- никаких медицинских данных, внутренней инфраструктуры и персональных сведений пациентов.

## Структура

- `index.html` — семантика и двуязычный контент;
- `app.css` — адаптивная система стилей;
- `app.js` — переключение RU/EN;
- `tests/layout.spec.js` — Playwright-проверки основных экранов и ссылок;
- `.github/workflows/pages.yml` — проверка и публикация на GitHub Pages.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Проверки:

```bash
npm install
npx playwright install chromium
npm run test:layout
```

## Откат

Предыдущая публичная версия сохранена в истории `main`. При необходимости изменения можно отменить отдельным revert-коммитом без переписывания истории репозитория.

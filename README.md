# Егор Белоусов — персональное портфолио

Одностраничный двуязычный сайт-портфолио о цифровом здравоохранении, геоаналитике и прикладных ИИ-системах.

## Архитектура

- `index.html` — семантическая структура и двуязычный контент;
- `app.css` — единая mobile-first система стилей с адаптивными сетками;
- `app.js` — переключение RU/EN, метаданные и лёгкие интерфейсные сценарии;
- `assets/` — локальные SVG-иллюстрации;
- `tests/` — Playwright-регрессии для мобильных, планшетных и десктопных экранов;
- `.github/workflows/pages.yml` — quality gate и публикация проверенной версии в `gh-pages`.

## Проверки качества

Перед публикацией CI проверяет:

- отсутствие горизонтального переполнения и пересечений блоков;
- корректность длинной типографики и первого экрана;
- загрузку всех локальных изображений;
- работу RU/EN без разрушения сетки;
- уникальность визуалов и текстовую иерархию;
- доступность основной информации без JavaScript;
- валидность ссылок, якорей и графических координат.

## Локальный запуск

```bash
python3 -m http.server 4173
```

Для полного набора проверок:

```bash
npm install
npx playwright install chromium
npm run test:layout
```

## Публикация

Изменения в `main` проходят Playwright-проверки. Только после успешного quality job статические файлы синхронизируются в `gh-pages` с cache-busting для `app.css` и `app.js`.

Публичная версия: `https://ryzenovod.github.io/cv/`

## Конфиденциальность

В медицинском проекте не публикуются рабочие медицинские данные, внутренняя инфраструктура и персональные сведения пациентов.

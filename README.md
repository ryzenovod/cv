# Егор Белоусов — персональное портфолио

Одностраничный двуязычный сайт личного бренда.

## Что внутри

- русский язык по умолчанию;
- переключатель RU/EN с сохранением выбранного языка;
- адаптивная вёрстка для телефона и десктопа;
- обезличенное описание медицинской геоаналитической платформы;
- проекты OpenRisk и APRU;
- достижения, образование и профессиональный фокус;
- никаких сборщиков и зависимостей: сайт целиком находится в `index.html`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите простой HTTP-сервер:

```bash
python3 -m http.server 8080
```

После этого сайт будет доступен по адресу `http://localhost:8080`.

## Развёртывание на nginx

```nginx
server {
    listen 80;
    server_name example.ru www.example.ru;

    root /var/www/cv;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

Скопируйте содержимое репозитория в `/var/www/cv`, замените домен и подключите HTTPS.

## GitHub Pages

В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.

## Конфиденциальность

В медицинском проекте не публикуются исходный код, инфраструктура, рабочие данные и персональные сведения пациентов.
